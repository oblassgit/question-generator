# Zufällige Frage

Öffne `index.html` im Browser. Sofort erscheint eine zufällige Frage. Mit
**Nächste Frage** wird eine andere Frage angezeigt, ohne die Seite neu zu laden.
Die Seite funktioniert ohne Installation, Build-Schritt oder Server und kann
auch auf einem statischen Webhost bereitgestellt werden.

Bearbeite die Fragenliste in `questions.js`, um die Fragen anzupassen. Die
Fragen sind dort nach Themen gruppiert; die Auswahl erfolgt zufällig aus der
gesamten Liste. Bei mehreren Fragen wiederholt sich die aktuelle Frage nicht
direkt hintereinander. Nach dem Neuladen beginnt die Auswahl von vorn.
Bei nur einer Frage ist die Schaltfläche deaktiviert; bei einer leeren Liste
wird ein Hinweis angezeigt.
